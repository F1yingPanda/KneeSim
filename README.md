Code designed for an Arduino Mega 2560 used in a Knee simulator for Dr. Anton of Tennessee Technological University. /src/ has code for the arduino as well as a control panel developed for use with LabVIEW

## Documentation
- [Pin List](pinout.md)
- [Wiring Diagram](WireDiagram.png)

## Dependencies
Install the following Arduino libraries:
- AccelStepper (tested with v1.64)
- Encoder (tested with v1.4.4)
- STM32duino VL53L4CD (tested with v1.0.5)
